# Travel Planner

Web aplikacija za planiranje putovanja razvijena koriscenjem React (Vite) frontend i Microsoft Service Fabric mikroservisnog backenda.





**Preduslovi**



* Visual Studio 2022
* Microsoft Service Fabric SDK
* SQL Express
* Node.js





**Pokretanje projekta**



* **Backend**



1. Pokrenuti SQL Server Express
2. Pokrenuti Service Fabric lokalni klaster
3. Otvoriti 'TravelPlannerApp.sln' u VS2022 kao **administrator**
4. Pokrenuti aplikaciju (Start/F5)



* **Frontend**



1. Pozicionirati se u 'frontend' folder
2. Instalirati zavisnosti: npm install
3. Pokrenuti aplikaciju: npm run dev
4. Otvoriti browser na 'http://localhost:5173'
